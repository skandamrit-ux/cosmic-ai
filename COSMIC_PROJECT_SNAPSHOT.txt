# COSMIC AI

COSMIC is a modular personal AI operating system designed as a device-independent AI core with mobile, computer, research, coding, automation, security, and future hardware interfaces.

## Architecture

User Interface → API → Kernel → Context/Memory/Identity → AI Gateway → Planner/Agents → Security/Permissions → Tools → Verification → State/Memory/Audit → Response

## Core Principles

- Real execution only; never simulate success.
- Every important action is permission-aware and auditable.
- Verification follows execution.
- AI providers remain replaceable.
- Android is a client/node, not the permanent brain.
- Local-first architecture.
- Cloud storage is optional backup/archive/synchronization.
- Authorized defensive cybersecurity only.
- Modular components with clear boundaries.

from flask import Flask, jsonify, request

APP_NAME = "COSMIC AI"
APP_VERSION = "0.1.0"

app = Flask(__name__)


@app.get("/")
def root():
    return jsonify({
        "name": APP_NAME,
        "version": APP_VERSION,
        "status": "running"
    })


@app.get("/api/health")
def health():
    return jsonify({
        "success": True,
        "service": APP_NAME,
        "status": "healthy"
    })


@app.post("/api/chat")
def chat():
    data = request.get_json(silent=True) or {}
    message = str(data.get("message", "")).strip()

    if not message:
        return jsonify({
            "success": False,
            "error": "message is required"
        }), 400

    return jsonify({
        "success": True,
        "type": "response",
        "message": message,
        "verified": True
    })


if __name__ == "__main__":
    app.run(host="127.0.0.1", port=8000, debug=False)

    path.parent.mkdir(parents=True, exist_ok=True)

"""Identity change history."""

class IdentityHistory:
    def __init__(self):
        self.entries = []

    def record(self, old_name, new_name):
        self.entries.append({
            "old_name": old_name,
            "new_name": new_name
        })

    def all(self):
        return list(self.entries)

"""Persistent COSMIC identity management."""

DEFAULT_IDENTITY = {
    "name": "COSMIC",
    "version": "0.1.0"
}


class IdentityManager:
    def __init__(self, identity=None):
        self.identity = dict(DEFAULT_IDENTITY)
        if identity:
            self.identity.update(identity)

    def get_name(self):
        return self.identity["name"]

    def rename(self, new_name):
        new_name = str(new_name).strip()
        if not new_name:
            raise ValueError("Identity name cannot be empty")
        self.identity["name"] = new_name
        return new_name

"""Execution verification boundary."""

class VerificationResult:
    def __init__(self, verified, details=None):
        self.verified = bool(verified)
        self.details = details or {}

    def to_dict(self):
        return {
            "verified": self.verified,
            "details": self.details
        }

# COSMIC Architecture

The architecture is divided into independent layers:

1. Interface
2. API
3. Core Kernel
4. Context and Conversation
5. AI Gateway
6. Memory and Identity
7. Security and Permissions
8. Tools and Execution
9. Research/Coding/Agents
10. Devices and Automation
11. Database/Sync/Backup
12. Verification and Audit


############################################################
FILE: ./docs/decisions/0001-foundation.md
############################################################
# ADR-0001: Modular Foundation

COSMIC uses a modular backend so AI providers, interfaces, devices, tools, memory systems and execution engines can evolve independently.

The Android client is treated as a node rather than the permanent location of the COSMIC intelligence core.


############################################################
FILE: ./docs/security/README.md
############################################################
# COSMIC Security

Security is a first-class subsystem.

All computer, network, browser, device and security actions must be:

- authorized
- permission checked
- auditable
- executed against an allowed target
- verified after execution

Cybersecurity functionality is limited to authorized defensive, testing, research, CTF and laboratory environments.

async function checkCOSMIC() {
    const status = document.getElementById("status");

    try {
        const response = await fetch("/api/health");
        const data = await response.json();

        status.textContent = data.success
            ? "SYSTEM ONLINE"
            : "SYSTEM ERROR";
    } catch {
        status.textContent = "BACKEND OFFLINE";
    }
}

checkCOSMIC();

def test_health_contract():
    from backend.app import app

    client = app.test_client()
    response = client.get("/api/health")

    assert response.status_code == 200
    data = response.get_json()
    assert data["success"] is True
    assert data["status"] == "healthy"
